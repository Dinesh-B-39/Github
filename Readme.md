Online Food Ordering Website
A simple web application that allows users to browse food items and place orders online.

Features
- Browse food items.
- Add items to cart.
- Calculate total price.
- Place orders.
Technologies Used
- HTML
- CSS
- JavaScript
How to Run
1. Download or clone the repository.
2. Open the project folder.
3. Open index.html in your browser.
